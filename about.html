About This Website

his website is a straightforward, beginner-focused project made entirely with plain HTML. No CSS or JavaScript were used at all. It includes four connected pages — Home, Profile, Gallery, and About — joined together by a simple navigation menu.

The main purpose of this website is to practice basic HTML structure: working with headings, paragraphs, lists, links, and images..
